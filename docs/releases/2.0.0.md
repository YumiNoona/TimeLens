# TimeLens 2.0.0

A unified release for the local Windows dashboard, native Android app, public website and browser companions, with a new product-focused README and real dashboard screenshots using synthetic example data.

## Highlights

- Local activity insights, chronological timelines, app and website breakdowns, privacy controls, focus blocking, and optional offline-work reconciliation on Windows.
- Android brings native navigation, System/Light/Dark appearance with animated switching, local history, goals, privacy controls and Comfort/Strict blocking.
- Additional Android browser adapters include Brave, Vivaldi and DuckDuckGo. All matching domain allowances apply; polling pauses at screen-off and protection resumes after unlock.
- Lightweight tracking improvements, lazy Android app lists, bounded icon caching and batched allowance calculations.

## Version reset and installation

This intentionally resets the desktop, website and Android displayed versions. Android's internal build code continues increasing. Browser companions retain their independent 8.3.1 version. Previously installed higher-version desktop applications will not automatically downgrade. Extension ZIPs are developer/source packages, not a promise of automatic store updates. The existing Firefox store listing remains separate.

The included Android preview APK is debug-signed for testing, not a production-signed update, and cannot update a differently signed existing installation. The original Android release signing key is unavailable. Any APK explicitly named `unsigned` is a build artifact and cannot be installed. Do not uninstall an existing installation or discard its data to try these builds. A production Android update requires the original key or an explicitly chosen replacement identity and migration plan.

Screenshots show the actual dashboard UI with synthetic example data, not personal activity. No cloud sync or Windows–Android pairing is implied; each device keeps its own local history.
