# TimeLens Android 3.0.0

An Android-only update. Windows, the website and browser companions keep their existing versions. Windows downloads remain available in the [desktop release](https://github.com/YumiNoona/TimeLens/releases/tag/v2.0.0).

- Immediate circular light/dark reveal, without waiting for history scans or animating the entire palette on every frame.
- Original app icon colors in both themes, a scalable stopwatch launcher icon, and no navigation tap bubbles or repeated device/build footers.
- A full-year history overview, period app totals and detailed saved-day visits. Selecting a date keeps the annual overview fixed. Aggregation runs off the UI thread and respects daylight-saving changes and explicit retention choices.
- One year is the default retention for new installations. Previously deleted or expired history cannot be reconstructed.
- The optimized testing APK is approximately 2.62 MiB instead of the former unoptimized debug package. It uses code/resource shrinking.

Verified locally with 32 JVM tests, 23 device tests, debug/preview lint and APK signature verification. Emulator checks are not a physical-device FPS guarantee.

## Installation and signing

The attached APK is an optimized, development-signed testing preview. The original production signing key remains unavailable. A differently signed existing installation cannot be updated in place with this APK. Do not uninstall your existing app simply to try it; export any history you want to keep before deliberately choosing a reinstall/migration. No production signing key was replaced and no private key is included in this release.
