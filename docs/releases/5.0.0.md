# TimeLens 5.0.0

This release continues the current v1–v4 desktop series with the latest tracking, privacy and dashboard improvements.

- Chrome and Firefox companions are both **7.1.0**, with local pairing, activity tracking and Notify/Strict focus controls.
- Fixed pairing another browser invalidating the first browser. Revoking access clears all paired profiles and pending codes.
- Restricted extension authentication tokens to the local desktop endpoint, including redirect protection.
- Restored Chrome packaging and compatibility tests. Local builds now generate fresh checksums.

Download **TimeLens-Setup.exe** to install or **TimeLens.exe** for standalone use. The extension ZIPs are provided for developer installation/store submission; Firefox signing and store review are separate.

**Version reset:** users running a removed 7.x desktop build must manually install 5.0.0, because their existing updater will not consider a lower version newer. History and settings remain local. If an extension store already has a version above 7.1.0, it cannot deliver this lower version as an ordinary automatic update.
