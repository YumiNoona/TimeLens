# TimeLens 6.0.0

- Exit freely from the tray when your app and website blocklist is empty, or all block timers have expired—even with a block password saved.
- See whether exit is protected before clicking, and jump directly to Manage Blocks from the tray.
- Clearer password-protection guidance and consistent exit checks across the tray and dashboard API.
- Fixed dashboard polling cleanup when the dashboard is unmounted.

Download **TimeLens-Setup.exe** to install, or **TimeLens.exe** for standalone use. Chrome and Firefox companions remain **7.1.0**; no extension update is needed. Existing 7.x desktop installations require a manual install of 6.0.0.
