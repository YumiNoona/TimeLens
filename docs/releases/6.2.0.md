# TimeLens 6.2.0 — Keep your time in focus

Long creative sessions deserve an accurate record. TimeLens 6.2.0 strengthens the tracking engine, corrects daily totals, and makes the desktop app more resilient when Windows callbacks or background work fail.

## Reliable tracking for long sessions

- **Five-second checkpoints:** uninterrupted Twinmotion, design, and development sessions are saved continuously, even when the foreground window never changes.
- **Foreground recovery:** periodic polling catches changes missed by Windows events. Unobserved gaps start a new segment instead of being credited as work.
- **Safer history recovery:** startup no longer substitutes an arbitrary 30-minute duration for an unfinished session, and valid legacy timestamp formats are preserved.

## Daily totals that make sense

- Sessions crossing local midnight are allocated correctly across the summary, apps, categories, heatmap, timeline, and exports.
- Foreground browser activity contributes to active time; website breakdowns remain a separate view of that usage.
- Short app switches remain visible in the timeline.
- Twinmotion and Blender receive built-in design categories.

## More dependable idle and desktop behavior

- Lock, disconnect, sleep, wake, and unlock transitions are handled explicitly.
- Idle timeout changes take effect during tracking. Foreground playback can sustain activity within a limit; background music no longer keeps an unrelated desktop app active.
- Foreground callbacks, input timers, and session notifications contain and log recoverable errors. A failed dashboard launch no longer shuts down the tray loop.
- Local runtime logs record startup, shutdown, and callback failures for troubleshooting.
- Keyboard counts record key-down events without also counting key-up events.

## Tested before release

Regression checks cover three-hour sessions, restart recovery, missed observations, midnight boundaries, idle and playback transitions, and injected callback failures. The packaged desktop app is also checked for startup, embedded dashboard/API operation, and native tray behavior.

**Upgrading:** install TimeLens-Setup.exe, or use the in-app updater. Existing activity data and settings stay on your computer. Time that was never recorded cannot be reliably reconstructed; the fixes preserve observed history and improve tracking going forward.
