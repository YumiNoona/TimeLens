# TimeLens 7.0.0

TimeLens 7 makes recorded activity easier to inspect, configure, and export.

- Browser now has **Overview**, **Visits**, and **Pages** views. Pick any date, search or filter sites, and see page titles, stored URLs, browser name, visit times, active duration, sessions, clicks, and keystrokes where available.
- Input activity now highlights total keystrokes, clicks, per-app share, and a visual keyboard/mouse mix. TimeLens still stores counts only—it never records typed text.
- Export today, the last 30 days, this month, this year, or a custom date range as CSV or JSON.
- Added the light **Paper** theme and polished filter, pairing, and block-exit controls.
- Browser connection setup now explains why pairing exists, supports one-click code copying, and links directly to extension setup.
- Added more idle thresholds, dashboard refresh rates, break intervals, history ranges, and retention choices.
- Tray exit remains protected only while a real, unexpired target is on the blocklist.

Download **TimeLens-Setup.exe** to install, or **TimeLens.exe** for standalone use. Chrome and Firefox companions remain **7.1.0**, so no extension update is required.
