# TimeLens 7.0.1

- Refreshed Today and History heatmaps with useful date ranges, active-day totals, precise durations and day details. Select a day to open its history.
- Cleaner category donut: removed category-name panels and labels; hover or focus for category details.
- Searchable timelines, expand/collapse controls and bars based on recorded time instead of gaps between sessions.
- Apps input updates with the dashboard; new input sorting, time shares and clearer empty states.
- Fixed sub-minute heatmap activity and input batches crossing midnight. Refresh controls and safer history loading keep dates and reports aligned.

Desktop update only: Chrome and Firefox companions remain **7.0.0** and need no update.

Includes the Windows installer, standalone executable and checksums. Automated tracking, startup and dashboard checks run before publishing. Missed OS events and unobserved downtime cannot be reconstructed; tracking is not guaranteed to be 100% accurate.
