# TimeLens 7.1.0

TimeLens 7.1 makes activity details and everyday settings easier to use.

- Browser includes date-aware **Overview**, **Visits**, and **Pages** views with visit times, active duration, titles, stored URLs, browser names, sessions, clicks, and keystrokes.
- Input activity shows useful totals, per-app share, and a visual keyboard/mouse mix without recording typed text.
- Export any specific month, whole year, preset period, or custom date range as CSV or JSON, with controls aligned cleanly beside their description.
- Added the light **Paper** theme, more idle/refresh/reminder/history/retention choices, and a polished Clear Filters action.
- Browser setup now provides separate Firefox and Chrome ZIP downloads, automatically copies new pairing codes when allowed, and clearly separates connection actions.
- Fixed the **Protect tray exit** control shape and kept exit protection limited to real, unexpired blocked targets.

Desktop, Chrome, and Firefox packages are all version **7.1.0**. Download **TimeLens-Setup.exe** to install, or **TimeLens.exe** for standalone use.
