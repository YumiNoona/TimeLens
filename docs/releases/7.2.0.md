# TimeLens 7.2.0

TimeLens 7.2 polishes daily controls and keeps the documentation aligned with the shipped behavior.

- Export activity now opens on **Last 30 days**, with CSV and JSON options for today, a month, a year, or an exact custom date range.
- Input activity keeps its Keys and Clicks columns visible at narrower widths and includes clearer app icons.
- Focus targets support custom durations in minutes, hours, or days alongside the existing presets.
- Settings places a Donate action beside Docs and opens the existing project support panel directly.
- Fixed the two-year retention option so the API accepts the value already offered in Settings.
- Audited the website, privacy policy, store submission notes, tracking reference, and README for current pairing, export, retention, browser-report, and version details.

Desktop, Chrome, and Firefox packages are all version **7.2.0**. Download **TimeLens-Setup.exe** to install, or **TimeLens.exe** for standalone use.
