# TimeLens 7.2.0

TimeLens 7.2.0 makes local activity tracking safer, leaner, and more reliable, with secure Firefox pairing and a new Privacy Center.

- Protects the localhost API with scoped dashboard and Firefox authentication.
- Improves tracker lifecycle, queue limits, audio-device recovery, and resource cleanup.
- Corrects retention, exports, storage reporting, and update rollback.
- Adds URL/title privacy controls, pairing management, and delete-all activity controls.
- Optimizes the Firefox extension and strengthens dependency and release checks.
