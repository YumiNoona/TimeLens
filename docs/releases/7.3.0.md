# TimeLens 7.3.0

TimeLens 7.3.0 refines the dashboard without changing the tracker’s resource profile.

- Reworks Timeline & history settings into a clearer, responsive layout.
- Redesigns the activity heatmap with legible summaries, range controls, and selected-day detail.
- Adds category names beside progress bars and in the donut detail.
- Shows durations as hours and minutes by default, with an optional seconds display.
- Formats Browser browse time as a human-readable duration.
