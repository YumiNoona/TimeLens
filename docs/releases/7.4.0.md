# TimeLens 7.4.0

TimeLens 7.4.0 makes extension and desktop upgrades safer and predictable.

- Preserves already recorded desktop history when Firefox is disabled, updated, or removed.
- Stores pending aggregate input batches until the desktop app accepts them, then retries them after reconnect, restart, re-enable, or extension upgrade.
- Keeps the Firefox add-on ID stable and publishes tagged versions to Mozilla Add-ons so existing installations update in place.
- Makes the website and desktop update feed select the greatest complete stable GitHub release instead of relying on API ordering.
- Keeps installer upgrades separate from the activity database, so installing a newer executable does not replace local history or settings.
