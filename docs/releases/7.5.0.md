# TimeLens 7.5.0

TimeLens 7.5 is a runtime, reliability, and maintainability release.

## Highlights

- Migrates the Native AOT desktop application and test suite to .NET 10 LTS.
- Ships matching 7.5.0 Chrome and Firefox companions from one canonical extension runtime.
- Preserves browser input through brief local API outages with a bounded durable queue.
- Fixes shutdown races across the local API, SQLite writer, input timer, tray dispatcher, and Windows hooks.
- Disposes the local web host deterministically and adds a repeated lifecycle soak regression.
- Converts startup and tracking regressions into standard xUnit projects discoverable through `dotnet test`.
- Extracts block-media validation and persistence from the API host into a dedicated component.
- Prevents update-feed host-header injection by using an explicitly configured HTTPS public origin.
- Requires valid, publisher-matching Authenticode signatures after a signed build is installed.
- Updates the .NET, Svelte, Vite, TypeScript, icon, SQLite, and test dependencies with clean vulnerability scans.
- Verifies Chrome and Firefox versions together in release automation.
- Enforces one exclusive foreground-app ledger across summaries, apps, categories,
  timelines, heatmaps, and exports, including repair-safe handling of stale overlaps.
- Adds duration-based native audio and web-media tracking for background playback,
  muted state, browser audible fallbacks, and Picture-in-Picture without inflating
  active-work totals.
- Shows browser-extension health, compatible version, and attribution coverage when
  browser minutes are incomplete.
- Preserves pairing across temporary local API rejection and isolates packaged smoke
  tests from the production port and database.

## Assets

- `TimeLens-Setup.exe` — per-user Windows installer.
- `TimeLens.exe` — portable self-contained Windows x64 application.
- `TimeLens-Chrome-Extension.zip` — Chrome/Edge/Opera companion.
- `TimeLens-Firefox-Extension.zip` — Firefox companion.
- `SHA256SUMS.txt` — SHA-256 checksums for all release assets.
