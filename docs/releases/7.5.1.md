# TimeLens 7.5.1

TimeLens 7.5.1 is an activity-accuracy and concurrent-media patch release.

## Highlights

- Enforces one exclusive foreground-app ledger across summaries, apps, categories,
  timelines, heatmaps, and exports, including repair-safe handling of stale overlaps.
- Tracks native audio and web media as duration-based concurrent activity, including
  background playback, muted state, audible fallbacks, and Picture-in-Picture.
- Keeps playback outside active-work totals, so listening to Spotify while coding
  records both facts without creating an impossible workday.
- Reports only the selected foreground tab as active browsing while allowing other
  tabs to report media playback through low-frequency, event-driven checkpoints.
- Shows extension connectivity, minimum compatible version, and attribution coverage
  whenever browser minutes may be incomplete.
- Preserves pairing across temporary local API rejection and isolates packaged smoke
  tests from the production API port and user database.
- Adds regression coverage for stale overlaps, app switching, PiP/background playback,
  transient authorization failures, clean shutdown, and packaged Windows behavior.

## Assets

- `TimeLens-Setup.exe` — per-user Windows installer.
- `TimeLens.exe` — portable self-contained Windows x64 application.
- `TimeLens-Chrome-Extension.zip` — Chrome/Edge/Opera companion.
- `TimeLens-Firefox-Extension.zip` — Firefox companion.
- `SHA256SUMS.txt` — SHA-256 checksums for all release assets.
