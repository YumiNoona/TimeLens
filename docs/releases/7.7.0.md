# TimeLens 7.7.0

TimeLens 7.7 makes browser pairing self-consistent and rebuilds the contribution calendar around the compact GitHub profile pattern.

## Highlights

- The extension now verifies its saved token with the desktop before claiming it is connected.
- Revoked or replaced tokens show a clear re-pair state without deleting recoverable extension data during ordinary desktop restarts.
- A successful pairing sends a heartbeat immediately, allowing Settings to progress from Connecting to Connected without waiting for the periodic alarm.
- Pairing codes have an explicit two-minute connecting state and return to a retryable state when they expire.
- The contribution calendar fits every week inside its card, removes the horizontal scrollbar, fixes missing month labels, and uses the full-width History layout.
- Both the desktop application and Chrome/Firefox companions are version 7.7.0.
