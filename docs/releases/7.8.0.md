# TimeLens 7.8.0

TimeLens 7.8 is a long-session accuracy and dashboard continuity release.

## Highlights

- Preserves continuous YouTube and other web-media playback when hidden-tab timers are throttled to one-minute checkpoints.
- Reconciles longer browser suspensions from actual media position and playback rate, while rejecting forward seeks and gaps longer than 30 minutes.
- Adds three-hour background-video, suspended-page, and seek regressions and keeps playback as concurrent media so it never inflates exclusive daily work time.
- Calculates browser attribution only inside the observed extension window instead of comparing against unrelated time before pairing or reconnecting.
- Replaces the misleading permissions warning with an explanation of genuinely unmatched regular-page time and suppresses noisy warnings for small or immature samples.
- Keeps the active dashboard page in the URL, including browser Back/Forward and refresh behavior.
- Constrains and centers the contribution heatmap so it does not stretch into a mostly empty full-width card.

The desktop application, dashboard, installer, Chrome companion, and Firefox companion are version 7.8.0.
