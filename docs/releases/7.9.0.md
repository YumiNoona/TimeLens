# TimeLens 7.9.0

TimeLens 7.9 is a documentation, explainability, and visual-quality release built on the accuracy work in 7.8. The desktop application, embedded dashboard, Windows installer, Chrome companion, and Firefox companion all report version 7.9.0.

## Tracking and explainability

- Documents the exclusive foreground ledger used by Active time, Apps, Categories, Timeline, and foreground-site summaries.
- Documents the separate concurrent-media ledger used for Spotify, background audio, picture-in-picture, and background web video. Concurrent playback is never added to primary Active time.
- Adds clear alt-tab and simultaneous-media examples, including why overlapping facts must not be summed as a workday.
- Corrects the Focus score guide to match production: productive active categories divided by scored active time, with Other excluded, a neutral 50 when only Other exists, and 0 when no active time exists.
- Explains duration-based media checkpoints, forward-seek rejection, conservative suspended-gap recovery, and why an update cannot backfill events that were never observed.
- Explains exactly when the browser-attribution warning appears and which restricted, private, pre-pairing, or profile-specific intervals may remain unmatched.

## Dashboard refinements

- Places the compact activity heatmap on the right of Today and adds a Focus breakdown card on the left.
- Keeps the GitHub-style 3-month, 6-month, and 1-year heatmap compact, responsive, and free of a page-level horizontal scrollbar.
- Enlarges the category donut without increasing its card footprint.
- Adds app-share progress bars and improves visual hierarchy on the Apps page.
- Derives category, progress, timeline, and heatmap colors from the selected theme for better contrast.
- Preserves the current page, selected date, refresh behavior, and browser Back/Forward navigation through URL state.

## Pairing and setup guidance

- Defines Pair, Connecting, Connected, Reconnect/Desktop offline, and version-mismatch behavior in the public guide.
- Clarifies that pairing persists across app, browser, and PC restarts and is performed separately for each browser profile.
- Clarifies private/incognito permissions and why foreground browser time can exist without a domain event.
- Updates the public privacy policy for media-position metadata, concurrent time accounting, local-only transport, retention, and explicit non-collection guarantees.

## Release artifacts

The GitHub release contains:

- `TimeLens.exe` — portable self-contained Windows application
- `TimeLens-Setup.exe` — per-user Windows installer
- `TimeLens-Chrome-Extension.zip` — Chromium-family companion package
- `TimeLens-Firefox-Extension.zip` — Firefox-family companion package
- `SHA256SUMS.txt` — checksums used by the updater and for manual verification

Existing activity data and settings remain in `%LOCALAPPDATA%\TimeLens` during an in-place update.
