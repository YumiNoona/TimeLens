# TimeLens 8.1.0

TimeLens 8.1 is a desktop-only dashboard layout release. The Windows app, embedded dashboard, website, and installer are version 8.1.0. The Chrome and Firefox companions remain version 8.0.0 because their tracking behavior, permissions, payloads, and pairing protocol did not change.

## Today

- Moves the unchanged Activity contributions heatmap to the left side of the overview row.
- Moves Day snapshot to the right and lets it use all remaining horizontal space.
- Keeps the heatmap at its existing maximum width instead of stretching its cells or card.
- Preserves the standard 16-pixel gap between the two cards.

## History

- Anchors Activity contributions to the left content edge instead of centering the two-card group.
- Widens At a glance to fill the rest of the row.
- Keeps both cards equal-height on desktop and stacked on smaller windows.
- Does not change heatmap cells, ranges, labels, interactions, or activity calculations.

## Browser companion compatibility

- Chrome companion: 8.0.0
- Firefox companion: 8.0.0
- Minimum companion accepted by the 8.1 desktop app: 8.0.0
- Existing paired profiles do not need to reconnect or reinstall the extension.

## Release artifacts

- `TimeLens.exe` — desktop 8.1.0
- `TimeLens-Setup.exe` — installer 8.1.0
- `TimeLens-Chrome-Extension.zip` — unchanged companion 8.0.0
- `TimeLens-Firefox-Extension.zip` — unchanged companion 8.0.0
- `SHA256SUMS.txt`

Existing activity and settings remain under `%LOCALAPPDATA%\TimeLens` during an in-place update.
