# TimeLens 8.2.0

TimeLens 8.2 is a desktop-side browser and media accuracy release. The Windows app, embedded dashboard, website, and installer are version 8.2.0. The Chrome and Firefox companions remain version 8.0.0 because their permissions, collection logic, payloads, and pairing protocol did not change.

## Foreground browser accuracy

- Uses the canonical exclusive foreground ledger for Browser summaries, Visits, Pages, hourly charts, exports, Apps, categories, and Timeline.
- Stops stale browser rows at the next observed foreground application instead of allowing the old browser window to claim time owned by VS Code or another app.
- Removes idle and away spans once in the shared ledger, preventing different dashboard pages from producing subtly different totals.
- Keeps focused website time bounded by foreground browser time and keeps the primary daily ledger below 24 hours.
- Preserves tab-switch partitioning, local-midnight splitting, privacy-normalized URLs, and input-batch deduplication.

## Web-media accuracy

- Reconciles media-element heartbeats with actual media-position progress instead of automatically charging every checkpoint gap.
- Omits buffering and non-advancing intervals while retaining playback proven before and after the stall.
- Rejects forward seeks as watched time and accounts for playback rate when translating content progress into wall-clock playback time.
- Reconciles the last proven interval when playback pauses.
- Keeps bounded recovery for browser-throttled or suspended background pages, but no longer allows an unproven tail to be filled by a later heartbeat.
- Continues to treat background and picture-in-picture media as a concurrent overlay, not additional foreground work time.
- Unions simultaneous media intervals for the headline total so multiple playing tabs cannot multiply elapsed wall time.

## Browser companions

- Chrome companion: 8.0.0
- Firefox companion: 8.0.0
- Minimum companion accepted by the 8.2 desktop app: 8.0.0
- Existing paired browser profiles do not need to reconnect or reinstall.

## Reliability and verification

- Adds regression coverage for stale foreground browser rows, continuous playback, buffering, resumed playback, pause boundaries, suspended-page recovery, and seek rejection.
- Updates the dashboard's transitive `devalue` dependency to a patched release; the production dependency audit reports no known vulnerabilities.
- Verifies the packaged Native AOT executable against a fresh isolated database, embedded dashboard, tray integration, local API, browser-block contract, settings, and custom block media.
