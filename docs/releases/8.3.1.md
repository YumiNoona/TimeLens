# TimeLens 8.3.1

Offline work is now optional and **off by default**, including when upgrading from 8.3.0.

- Enable **Settings → Tracking → Offline work** to show the offline work panels in Today and History.
- Turning it off hides the panels and stops their requests and refresh timer. Existing offline entries are preserved and become visible again when enabled.
- The choice is saved across app restarts. Automatic idle detection and normal activity tracking are unchanged.
- Chrome and Firefox companion packages are versioned 8.3.1 and include the current privacy and lightweight tracking improvements.

Download `TimeLens.exe` for the standalone Windows app. The Firefox ZIP is an unsigned source package, not a Mozilla-signed installable add-on. No new installer is included.
