# TimeLens 8.4.0

More usable mobile navigation, stronger release checks and the first independent native Android preview.

## Windows and dashboard

- Phone-width dashboards now use Today, Apps, Timeline and Block tabs plus a More dialog for History, Browser, Rules and Settings. Larger touch controls and safe-area spacing keep navigation accessible on small screens.
- Fixed dashboard type errors in timeline calculations and obsolete Apps properties. Every dashboard build now checks Svelte components as well as TypeScript.
- Authenticated dashboard activity renews the local session instead of expiring after twelve hours of continuous use.
- Failed dismissal of the release notice now offers an actionable error and retry instead of an unhandled request rejection.
- Updated Vite to 8.3.5 in both frontends, addressing the high-severity build-tool advisory. Two low-severity advisories remain in the Svelte plugin's build-only deepmerge dependency; no upstream fixed release was available during verification.
- Offline work remains optional and off by default. Browser companions remain 8.3.1; this release does not change their scripts or require a new extension installation.

## Android preview

`TimeLens-Android-preview.apk` is a **debug-signed evaluation build**, separate from the stable Windows app. It supports Android 10+ with native Today, Apps, Timeline, Focus and Settings tabs; tablet navigation; Usage access onboarding; local SQLite history; app categories/search; daily/app budget status; a saved focus deadline; privacy exclusions; retention; light/dark/system themes; and selected-day CSV/JSON exports.

The app requests no Internet permission and does not require a PC. Its first version imports recent system usage events when opened/refreshed, so older history exists only when previously archived. Website/media detail, strict blocking, background timer alarms, scheduled archival and optional local PC pairing are **not implemented**. A later debug build may require reinstalling due to a different debug signing key; export first.

The [Android roadmap](https://github.com/YumiNoona/TimeLens/blob/v8.4.0/docs/android-roadmap.md) maps every desktop capability and describes optional encrypted local PC pairing while keeping both apps independent.

## Downloads

- `TimeLens-Setup.exe`: recommended Windows installation.
- `TimeLens.exe`: standalone Windows executable.
- `TimeLens-Android-preview.apk`: Android evaluation build.
- Chrome/Firefox extension ZIPs: developer/review packages; the official Firefox listing remains the signed installation channel.
- `SHA256SUMS.txt`: checksums for the downloadable assets.
