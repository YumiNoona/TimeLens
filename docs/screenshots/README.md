# Dashboard screenshots

These screenshots show the actual dashboard with synthetic example activity. They contain no private activity history. They are generated from the built dashboard, not a separately designed mockup.

To reproduce, build the dashboard, then run node scripts/readme-preview.mjs. The preview binds only to the loopback interface, serves the built dashboard with a small synthetic API, and never opens a personal database. Capture Today, Timeline and Browser in the browser and save the images here. The preview is a documentation tool, not part of the shipped app or its tracking pipeline.
