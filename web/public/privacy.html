Your activity stays yours.

Effective October 29, 2026 · Windows and Android 1.0.0 · Browser companions 9.0.0

What is collected

Windows stores foreground application activity, idle/away intervals, configured website observations, supported media timing, and optional aggregate keystroke/click counts. URL detail and page-title storage follow your privacy settings. Browser companions never read typed characters, key values, form contents, passwords or page contents.

Android stores local app usage and, only when enabled after disclosure, domains exposed in supported browser address bars. Accessibility supports optional app/site blocking. It does not collect global input counts, passwords, page contents, URL paths or search queries. A private browser tab can be observed on Android if its browser exposes the address bar. Browser extensions exclude private/incognito tabs.

Where it stays

Browser companions send observations only to the local Windows service at 127.0.0.1:47821. Windows stores data under %LOCALAPPDATA%\TimeLens; Android uses app-private storage and requests no Internet permission. There is no required account, cloud activity database, advertising profile or analytics SDK. Windows and Android do not currently sync.

Your controls

Control optional collection, exclusions, URL/title detail, retention, recording pauses and local deletion in the available platform settings. Exports leave the device only when you choose to save/share them. Treat exported history as personal data. App-activity exports are not full backups of every rule, preference or PIN.

Browser-local state

The companion stores its pairing credential and bounded pending aggregate input batches locally. Batches are privacy-filtered, validated and retried using stable identifiers. Uninstalling the extension clears its own state, not the Windows activity database. Disabling collection does not automatically erase historical records; use the deletion controls.

Permissions and downloads

Browser tab/site permissions support website observations, aggregate input counts, media detection and configured blocks; alarms provide bounded recovery. Extension code is packaged locally with no remote executable code. Android Usage access reads app activity; Accessibility and optional administrator controls have separate purposes and user setup.

The website, GitHub and browser stores handle normal download/update requests. Windows update checks may contact the release service and GitHub; those requests do not include activity history. Store publication and review are separate from building release packages.

Questions

See the user guide or project issue tracker. Never post private activity exports or credentials in public issues.
