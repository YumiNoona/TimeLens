TimeLens privacy policy

Effective September 8, 2026 - TimeLens 7.0

The TimeLens extension reads the selected tab URL, title, domain and audible status in focused normal browser windows. Private windows are excluded. On focused visible web pages, the extension also counts trusted clicks and keystrokes. It never reads typed characters, key values, passwords or form contents. Pending input batches stay in memory for up to two minutes for retry; received counts are deduplicated by batch ID.

Where information goes

Activity goes only to the TimeLens Windows app at 127.0.0.1 on the same computer. The app stores it in a local SQLite database. TimeLens does not send browsing activity to cloud storage, advertising networks or analytics providers, and does not sell it.

Use and control

Activity supports your time reports and website focus controls. Disable browser tracking or input counting in desktop settings. Records follow your retention settings. Exports are created at your request and you control their sharing. Uninstalling the extension stops collection but preserves desktop history. To remove all history, close TimeLens and delete activity.db and its activity.db-wal and activity.db-shm files, if present, from the TimeLens folder in Windows local application data.

Permissions

Tab access identifies the selected website. Website access supports aggregate input counting and configured focus reminders. Alarms refresh local tracking and settings. Extension storage supports upgrade cleanup. Executable extension code is packaged locally.

Other connections

The desktop updater may contact the TimeLens release service and GitHub for metadata and updates. Activity is not included in these requests.
