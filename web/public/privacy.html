TimeLens privacy policy

Effective September 16, 2026 - TimeLens 7.5

The TimeLens extension reads the selected tab URL, title, domain and audible status in focused normal browser windows. Private windows are excluded. On focused visible web pages, the extension also counts trusted clicks and keystrokes. It never reads typed characters, key values, passwords or form contents. Pending aggregate input batches are kept in extension storage until the local desktop app accepts them; received counts are deduplicated by batch ID.

Where information goes

Activity goes only to the TimeLens Windows app at 127.0.0.1 on the same computer. The app stores it in a local SQLite database. TimeLens does not send browsing activity to cloud storage, advertising networks or analytics providers, and does not sell it.

Use and control

Activity supports your time reports and website focus controls. Disable browser tracking or input counting in desktop settings. Records follow your retention settings. Exports are created at your request and you control their sharing. Disabling, updating, or uninstalling the extension never deletes desktop history. Extension-local state persists across disable and update; uninstalling an extension clears its local state, so any batch not yet accepted by the desktop app cannot be retained after uninstall. To remove desktop history, use the Privacy center’s delete control.

Permissions

Tab access identifies the selected website. Website access supports aggregate input counting and configured focus reminders. Alarms refresh local tracking and settings. Extension storage preserves pairing and pending aggregate counts across restart, disable, and update. Executable extension code is packaged locally.

Other connections

The desktop updater may contact the TimeLens release service and GitHub for metadata and updates. Firefox may contact Mozilla Add-ons for signed extension updates. Activity is not included in these requests.
