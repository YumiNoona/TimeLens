TimeLens privacy policy

Effective September 17, 2026 — TimeLens 8.0

TimeLens is a local-first Windows activity tracker. The desktop app records the foreground application, aggregate keyboard and mouse counts, idle state, and optional audio-session metadata. The browser companion reads the selected normal-tab URL, title, domain, and audible state. On supported web pages it also reports aggregate trusted input counts and media-element timing checkpoints such as playback position, duration, paused state, and playback rate.

What TimeLens does not collect

TimeLens does not record key values, typed text, passwords, form contents, page contents, screenshots, microphone audio, speaker audio, or video frames. Media timing metadata is used only to calculate duration; it does not contain the media itself. Private or incognito windows are excluded unless you explicitly allow the extension there.

Where information goes

Activity travels only between the extension and the TimeLens Windows app at 127.0.0.1:47821 on the same computer. The app stores it in a local SQLite database under %LOCALAPPDATA%\TimeLens. TimeLens does not send activity to cloud storage, advertising networks, or analytics providers, and does not sell it.

Time accounting

Foreground application and site time use one exclusive ledger. Media playback is stored as a separate concurrent signal because music or video can continue while another application is foreground. TimeLens does not add concurrent media to the primary Active time total.

Use and control

Activity supports local reports, goals, reminders, and website focus controls. Disable browser tracking, aggregate input counting, page-title storage, or audio signals in desktop settings. Records follow your retention setting. Exports are created only at your request and you control their sharing.

Disabling or updating the extension does not delete desktop history. The extension preserves pairing and pending aggregate batches across normal restart, disable, and update. Uninstalling it clears extension-local state, including any batch not yet accepted by the desktop app. To remove desktop history, use the Privacy center delete control.

Permissions

Tab access identifies the selected website. Website access supports aggregate input counting, duration-based media detection, and configured focus reminders. Alarms maintain local tracking checkpoints. Extension storage preserves pairing and pending aggregate counts. Executable extension code is packaged with the extension; TimeLens does not load remote code.

Other connections

The desktop updater may contact the TimeLens release service and GitHub for release metadata and checksummed downloads. Firefox may contact Mozilla Add-ons for extension updates. Activity data is not included in those requests.
